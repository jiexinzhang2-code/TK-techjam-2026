# Submission Deliverables

This directory is the submission-ready package for the KuaiRand-Pure project.

1. [`DEVPOST_PROJECT_DESCRIPTION.md`](DEVPOST_PROJECT_DESCRIPTION.md) — copy-ready written project description.
2. Public repository — <https://github.com/jiexinzhang2-code/TK-techjam-2026/tree/feature/bpr-fm>
3. [`RUN_ITERATION_LOG.md`](RUN_ITERATION_LOG.md) and [`run_iteration_log.jsonl`](run_iteration_log.jsonl) — human- and machine-readable 15-iteration audit logs.
4. [`RESULTS_AND_RESOURCES.md`](RESULTS_AND_RESOURCES.md) — validation results, official-baseline deltas, autonomy, tokens, wall-clock, iterations, and GPU usage.
5. [`final/`](final/) — selected config, validation summary, checkpoint, SHA-256 manifest, and Starter Kit-format test submission.

KuaiRand-1k and KuaiRand-27k were not attempted. All reported scores are KuaiRand-Pure validation scores; the test submission was exported without evaluating test labels.
